Follow the modules in number order:

| --- | --- | --- |

## How to use each module

1. Read the matching `.md` guide.
2. Activate the `scientific-basics` Conda environment.
3. Open the matching `.py` file in VS Code.
4. Run the `# %%` cells from top to bottom.
5. Complete the copy-and-paste practice.

Keep each `.py` file next to its data file. This lets commands such as
`pd.read_csv("02_reading_csv_data.csv")` work without changing the code.
